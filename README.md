# 📒 Tour Collection Manager

Class 9 ke tour collection ka **offline Android register**. Internet ki zarurat nahi, sara data phone me hi rehta hai.

## ✨ Features
- Student ka naam, section (A/B/C) aur amount add karo
- Entry **Edit** ya **Delete** karo
- Section-wise aur total collection ek nazar me
- **PDF report** download karo
- **Excel CSV** export karo (backup ke liye)

## 📥 Download kaise kare
1. Upar **Releases** par jao (ya seedha: `https://github.com/Ajaxbhau/Tour-collection-guide/releases/latest`)
2. **Assets** me `app-debug.apk` par tap karo
3. Download hone ke baad file kholo aur **Install** dabao
4. Agar phone maange to **"Install unknown apps"** allow kar do

## ⚠️ Dhyan rakhe
- Data sirf isi phone me save hota hai. Regular **CSV export** karke backup rakho.
- App uninstall karne par data delete ho jata hai.
